# element-ai-vue-ppt 本期任务分区与验收

日期：2026-10-30  
关联方案：[DESIGN.md](./DESIGN.md)  
状态：待评审，任务均未开始。任务分区用于安排实现顺序，不代表已经实现，也不是把新增要求移到下一期。

## 1. 本期交付定义

本期必须同时交付：

- 可独立发布/使用的 element-ai-vue-ppt 核心包。
- packages/components/ppt 对核心包的 ElAPpt 包装。
- PPTX 与旧版 PPT 的输入、预览、编辑、输出闭环。
- 桌面与移动端编辑。
- 多人实时协作、自部署服务、断线和重启恢复。
- 母版、布局、占位符、主题及其继承的完整编辑闭环。
- URL、本地文件、文件字节流、生成事件流输入。
- 全局生成只读、完成后编辑、取消/恢复、资源收尾。
- 兼容性、独立包安装、真机和 Office 互操作验证材料。

演示播放/媒体/动画作为方案中的补充建议，单列 T12 供本次评审；不影响“完整母版编辑”作为已确认要求。

## 3. 分区具体任务

### T00：范围、样本与接口基线

- 建立 PPTX Transitional、Strict、PowerPoint/WPS 来源和旧 PPT 样本库，记录许可与参考截图。
- 对文字、图片、形状、表格、图表、SmartArt、母版、主题、组合和目标效果逐项登记显示/编辑/导出要求。
- 确定 XmlAdapter、PackageStore、Command、ObjectRef、Diagnostic、Source、SnapshotStore、ConversionAdapter 契约。
- 确定文档 epoch、revision、操作 opId、流式 seq 和临时 clientId 的关系。
- 锁定桌面、移动端目标设备/浏览器版本，选定基准机器和性能预算。
- 将加密/签名文件的支持路径和验证样本单列，不通过后缀伪装支持。

验收：其他分区能使用同一契约和样本工作；未知能力有明确验证任务，不能默认为已支持。

### T01：独立包与构建隔离

- 在 packages/ppt-editor 建立 name=element-ai-vue-ppt 的独立包、许可证和公开 README。
- 输出根入口、core、collaboration、stream、server、style.css，分离浏览器与 Node 依赖。
- 提供 Vue 组件与命令式挂载两种入口，核心只依赖公开 npm 模块。
- 声明 Vue peer dependency，明确文本协作依赖的实例/版本约束。
- 核心自带样式、图标与模板；可独立构建、测试、pack。
- 主库 modules/style/type 全目录扫描排除核心源码与服务端；不复制第二套核心产物。
- 修改发布工具支持独立选择、依赖顺序和恢复，不执行未经授权的正式发布。

验收：tarball 可在仓库外安装；导出路径/声明/Worker/模板有效；SSR 导入不访问 window；浏览器产物不包含 Node server 模块。

### T02：OPC/OOXML 内核

- 实现解包、Content Types、关系图、目标路径解析及输入预算。
- 实现 Strict/Transitional 类型识别与 XML namespace 适配。
- 导入页面顺序、资源、布局、母版、主题和扩展；保留原始部件。
- 实现原子事务、对象 ID 映射、脏部件和语义校验。
- 实现依赖闭包复制、资源共享、删除引用检查。
- 跨变体复制按目标 Strict/Transitional 适配整个依赖闭包；不能安全转换时原子拒绝，覆盖模板和母版实例化。
- 提供本地与服务端共用的确定性命令执行核心，Node XML 适配可运行。

验收：原样往返不丢部件；修改不破坏无关 XML/关系；失败事务回滚；不同运行端产生等价标准语义；Strict 与 Transitional 双向复制不产生混合包。

### T03：渲染与排版

- DOM/SVG 页面、元素、组坐标、绘制顺序和命中测试。
- 字体、文本片段、段落/列表/间距、自适应、占位符与主题继承。
- 图片裁剪、形状几何、线条、支持的效果。
- 母版/布局/页面分层展示、属性来源和依赖缓存失效。
- 页面虚拟化、缩略图、资源缓存、加载诊断。

验收：目标样本与 Office 参考画面逐项比对；缺失字体明确报告；缩放不修改文档尺寸；基础页和复杂页均有性能记录。

### T04：基础编辑与事务

- 选择/多选、拖拽、缩放、旋转、对齐/分布、图层、锁定。
- Tiptap 与 DrawingML 文本结构双向映射，保留格式和未知数据边界。
- 中文输入组合、文本选区、剪贴板、键盘快捷键。
- 插入/替换图片、插入/删除图形、受控几何/样式修改。
- 本地历史和协作历史统一命令接口，不能将整包快照回滚当作多人撤销。
- 文本编辑结算与外部生成开始、导出、切换文档协调。

验收：一次拖拽一个撤销步骤；改标题不丢其他文字样式；文本输入不被选区/远端更新打断；错误命令不污染正式文档。

### T05：高级对象与页面管理

- 表格行列、合并、单元格富文本、边框/填充及编辑。
- 目标图表类型、系列/数据、图例/坐标轴及关联数据写回；嵌入数据修改由适配器处理，不偷换为图片。
- SmartArt 的对象类型/布局清单与对应结构编辑，扩展对象保持可追踪诊断。
- 分组/解组、组内坐标、连接线端点和依赖更新。
- 页面新增、删除、排序、复制、跨文档复制及依赖去重。
- 复制/删除事务与协作冲突规则联调。

验收：受支持表格和图表在导出文件中仍保留对应可编辑对象；跨文档复制主题/资源正确；页面删除不产生悬空关系。

### T06：完整母版、布局和主题

- 独立母版工作区、母版/布局树、普通页和母版页切换。
- 母版/布局增删改查、复制、重命名、引用迁移。
- 占位符类型/编号、文本级别、位置/样式和页面实例映射。
- 主题色、字体、效果、背景、母版对象、页脚等。
- 局部覆盖、清除覆盖、重置布局、隐藏母版图形。
- 母版跨文档复用与依赖闭包复制。
- 修改母版影响所有引用页面，跨页缓存与远端同步更新。

验收：修改母版标题字体能同步影响无覆盖的子页，同时保持已覆盖页面不变；删除在用布局必须迁移且不丢内容；导出后 Office 中仍是母版/布局关系。

### T07：多人协作、权限和持久化

- 自部署 Node WebSocket 服务与身份/权限/资源适配接口。
- 有序语义命令、服务端 revision、实体版本前置条件和 opId 去重。
- 每文本对象 Yjs CRDT、初始化/epoch、schema 校验与标准文本写回。
- 键盘、工具栏、AI、母版与表格单元格文字均经统一文本协调层；测试文字和格式命令不会造成 XML/CRDT 双写竞争。
- 在线用户、远端光标/选区和拖拽临时状态。
- SQLite/WAL 日志、文件资源/检查点、同提交边界的 CRDT/OOXML 快照。
- 掉线恢复、服务重启回放、权限撤销和资源授权。
- 作者范围撤销/重做；结构冲突拒绝/重试，保留未确认草稿。
- 与生成租约协调，拒绝被锁定期间的人工写入。

验收：至少三客户端覆盖同文本输入、同时拖拽、删除冲突、母版变更；不同断开/重启时刻恢复到一致结果；被拒绝编辑不丢失本地草稿且不污染其他客户端。

### T08：输入适配与生成会话

- 统一 source，支持 URL、File/Blob/ArrayBuffer、文件字节流、完整事件流。
- 实现 SSE/NDJSON 跨 chunk 缓冲、取消/超时/鉴权适配。
- 区分下载进度与逐内容生成；文件字节流未完整前不冒充可编辑 PPT。
- 创建标准候选包、布局模板实例化、内容/富文本/资源操作。
- 候选分支包含标准包、CRDT、对象/文字映射和日志，完成/接受/丢弃时原子切换检查点与 epoch，不能只替换包文件。
- 全局租约与 fencingToken、人工编辑交接、seq 去重/缺号/恢复。
- 异步图片顺序与最新属性、资源失败重试/移除、收尾校验。
- 重连/刷新恢复的生成检查点、取消/丢弃/接受草稿。
- 同文档 replace/append 及协作房间初始化权限。

验收：发起者和其他客户端都在生成时只读；事件重放不重复文字；图片下载顺序不改变图层；旧 token 和旧 source 的异步结果不覆盖新文档；旁观者卸载不取消生成、发起者掉线不丢候选；生成完成后的首次文字编辑、分支丢弃或服务重启后，文字、格式、映射与标准包保持一致。

### T09：旧版 PPT 转换及特殊文件

- 实现 ConversionAdapter 与可自部署 LibreOffice 转换服务，不只留接口。
- 文件类型检测、任务上传/下载、版本记录、隔离工作目录、超时/并发上限。
- PPT → PPTX 导入与 PPTX → PPT 输出，保留原文件。
- 密码接口/隔离解密流程与支持样本，密码不写日志。
- 签名失效提示与编辑副本输出规则；损坏文件报告。
- 转换结果重新进行标准校验和兼容分析，返回已知变化与未知损失声明。

验收：旧版 PPT 经服务导入后可编辑、导出并被 Office 打开；转换失败不变成空白成功；无服务时返回可操作的 CONVERSION_REQUIRED。

### T10：移动端完整编辑

- Pointer Events 和手势优先级：元素操作、双指画布、文本原生选区。
- 移动工具栏、属性抽屉、页面导航和母版工作区。
- 触摸命中区、虚拟键盘、VisualViewport、安全区域和旋转。
- 中文输入、文件选择、图片插入、导出/下载/分享。
- 多人协作、全局生成锁和中断恢复的移动交互。
- 内存/渲染预算和真机性能修正。

验收：iOS/Android 真机完成“打开 PPTX/PPT → 编辑文字/图片/母版 → 协作 → 导出”；不能仅提供缩窄版桌面 UI。

### T11：导出、标准兼容与保留

- 本地提交点与协作已确认 revision 快照导出。
- 标准关系和命名空间校验，脏部件局部序列化、未知内容保留。
- 普通 PPTX、Strict PPTX、服务转换旧 PPT 的输出路径。
- 未解决资源、签名变化、格式损失和未同步操作的明确反馈。
- 正式 revision 与候选 branchRevision 分离；生成期间禁止导出候选包，接受草稿后的输出必须来自完整提升检查点。
- Open XML SDK 检查与 PowerPoint/WPS 互操作样本归档。

验收：无新增修复提示；对象保持目标可编辑性；其他人的修改不因导出或撤销丢失；检查点与导出 revision 一致。

### T12：演示播放与媒体（补充建议）

- 全屏/窗口/移动端播放、页面导航、播放控制。
- 页面切换、基础对象进入/退出/强调动画和目标时间线。
- 音视频资源、浏览器用户手势要求和播放失败提示。
- 播放与编辑状态分离，保留标准动画/媒体数据。
- 复杂效果清单逐项实现，无法模拟的效果明确报告。

验收：目标样本动画顺序/时间、媒体和切页符合定义；不把静态预览称为动画播放；导出不删除原时间线。

### T13：ElAPpt 集成与文档

- 主库公开依赖、ElAPpt 包装、事件/插槽/实例方法转发。
- theme-chalk 变量映射与独立 CSS 入口，避免双份样式。
- 文档更新为独立包和主库两种接入方式。
- 示例包含链接、旧 PPT、本地文件、流式、移动、母版、协作服务。
- 主库类型和构建排除核心源码，保持已有注册方式。

验收：独立 PptEditor 与 ElAPpt 对相同事件/文件的功能一致；不安装主库也可单独使用；现有组件构建不受破坏。

### T14：综合验收与发布准备

- 联合样本、协作、移动端、标准校验和性能报告。
- 包 LICENSE/NOTICE、依赖版本、字体模板来源和服务部署说明。
- 在干净项目安装 tarball 测试所有公开入口及样式/Worker。
- 主库与核心版本依赖、发布顺序、失败恢复与回滚说明。
- 所有已确认本期分区检查通过后才进入正式版本发布流程。

验收：提供可复现记录和实际结果；剩余缺陷明确列出，不能把占位、锁定或“架构已预留”计为功能完成。

## 4. 建议执行顺序

```text
T00 接口/样本
  → T01 包边界
  → T02 标准内核
  → T03/T07/T09 的基础能力
  → T04 编辑命令
  → T05/T06/T08/T10 各工作区与联调
  → T11 导出兼容
  → T12 播放（纳入补充建议后）
  → T13 主库集成
  → T14 完整验收
```

T07 可在 T02 后先实现服务存储与顺序接口，文本协作完整验收等待 T04；T10 可提前实现响应式布局，但完整验收等待母版/协作/生成能力。并行只在契约稳定后开展，不并行修改同一文档事实来源。

## 5. 完成判定

每项状态使用：未开始、进行中、待联调、待验证、完成。只有实际运行和对应样本通过后才标记完成。项目总完成条件是所有已确认本期分区完成，而不是文件夹创建、API 定义或基础 Demo 可运行。
