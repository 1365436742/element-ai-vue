# 实施记录

依据：[DESIGN.md](./DESIGN.md)、[TASKS.md](./TASKS.md)。用户已确认开始实现；全部已确认分区保留在本期范围，未完成的分区不得计为支持。

## 全局约束

- 包名 `element-ai-vue-ppt`，主库 `ElAPpt` 仅封装。
- OOXML 部件是事实来源，保留未知 XML/资源；派生场景只用于渲染。
- 独立浏览器包不得引入 Node 服务模块；Vue 为 peer。
- PPT 通过自部署转换服务；PPTX 浏览器直接处理。
- 流式生成期间禁止人工修改，显式完成后提交；异常保留恢复路径。
- 协作、移动编辑、母版均属于本期；状态必须以测试证据为准。
- 不发布 npm、不提交或推送 Git，所有改动留在当前功能分支供用户查看。

## Task 1: 标准文档内核

范围：`src/core/**`、`tests/core.test.ts`。共享类型位于 `src/types.ts`。

实现 `OfficeDocument.create(title?)`、`OfficeDocument.load(Uint8Array)`、`getScene()`、`execute(Command)`、`export():Uint8Array`、`clone()`。使用 fflate 和 @xmldom/xmldom。标准 PPTX 默认创建真实主题/母版/布局/页面关系。检测 Transitional/Strict。原始部件保留，修改只写脏 XML。采用事务失败回滚。

场景坐标使用像素，96dpi，EMU=px\*9525。页面对象引用采用 part+id。读取文本/图片/基本形状、组变换、表格和母版布局继承；未知对象报告，不能假装支持。基本命令包括文本、形状、图片、位置、样式、页面增删复制排序、主题/背景、母版/布局对象编辑。导入关系路径和预算检查。图片返回 data URL。所有路径须验证。

验证：独立手工 OOXML fixture 的页面顺序/继承；未知部件及扩展保留；文字编辑不丢无关格式；事务失败不改变包；非法 ZIP/关系路径拒绝；导出再导入。

## Task 2: 编辑器、输入和包集成

范围：`src/types.ts`、`src/controller.ts`、`src/ui/**`、`src/stream/**`、包构建和 demo、主库包装。

使用 frontend-design：暖白纸面、墨色文字、橙色强调、网格工作画布，缩略图/舞台/属性三栏；移动端底部工具和属性抽屉，键盘与 Pointer Events。工作 Vue 组件及命令式挂载，真实内核编辑；文件导入、链接输入、导出、撤销重做、页面管理、母版入口、图片、文本、形状。事件流序号去重/缺号检测、候选文档、显式完成/失败状态、生成只读。文件字节流完成后解析。独立 ESM/CJS/声明/样式构建，主库构建隔离。

验证：控制器状态转换与异步源竞争、流分块；包 typecheck/build；浏览器桌面/移动交互；主库类型构建回归。

## Task 3: 协作与旧 PPT 服务

范围：`src/collaboration/**`、`src/server/**`、`tests/server.test.ts`、部署说明。

实现可运行 Node 服务，鉴权/房间权限、服务器排序与版本冲突、操作去重、持久化检查点、断线恢复。文本通过统一 CRDT 协调器，生成锁在服务器执行。客户端连接和在线状态。LibreOffice 独立目录/进程/超时/并发限制转换适配器和 HTTP 服务，明确服务依赖。

验证：真实本地服务多客户端并发、权限、断线/重启、生成锁；转换失败/超时。真实 Office/LibreOffice 环境缺失时不得把互操作标记为已验证。

## Task 4: 完整能力补齐与综合验收

对照 T00–T14 补齐高级对象、完整母版继承/迁移/跨文档复制、协作撤销/富文本、移动真机和标准校验。执行独立审查、tarball 外部导入、主库构建。不能将基础闭环等同于完整 PowerPoint 引擎。
